# ZHL Productivity Pack

Five workflow tweaks for Zillow Home Loans, Salesforce, Genesys, and Gmail bundled into one Chrome extension. Each one can be turned on or off from the setup page.

## Install (load unpacked)

1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick this `extension/` folder.
4. The setup page opens automatically the first time. You can reopen it any time by clicking the extension's toolbar icon, or from `chrome://extensions` → ZHL Productivity Pack → **Details** → **Extension options**.

## What's in the pack

| Module | Runs on |
| --- | --- |
| Gmail & Salesforce QoL | mail.google.com, *.lightning.force.com |
| Salesforce Contact SMS Quick Open | *.lightning.force.com, *.salesforce.com |
| ZHL Loan Amount Field | operator.zillowhomeloans.com/loan-officer-portal |
| VA Residual Income & Student Loan Calc | operator.zillowhomeloans.com |
| Genesys Caller ID for Salesforce | *.lightning.force.com, *.mypurecloud.com + related |

Toggling a module off and reloading any open tab on the affected site stops it from running.

What's new

✨ New features

The latest additions, pulled from each app section below so you don't have to scroll for them.

🏠 Loan Officer Portal

Runs on: operator.zillowhomeloans.com/loan-officer-portal

Copy addresses primary → co-borrower

Full application → Addresses → empty co-borrower section

One click re-adds every address on the primary borrower's list for the co-borrower. Picks each address via LOP's built-in "Use existing address" dropdown, then fills the fields LOP leaves blank: address type, housing type, dates, monthly rent, and the "Mailing same as current" checkbox.

  • Confirm prompt only if the co-borrower already has rows (prevents accidental duplicates).
  • Works for files with 3+ borrowers — the button appears on every co-borrower section.

FHA Manual Underwrite eligibility pill + Analyzer

Full application → Credit section

Reads the three bureau scores for each borrower, takes the middle, then uses the LOWER middle across borrowers. Shows green ✓ when ≥ 640, red ✗ when below.

Click the Analyze Manual UW button next to the pill for the full workup — it reads DTI, PITI, total assets, current rent and the unit count from the page, evaluates every ratio tier (31/43, 37/47, 40/40, 40/50) and compensating factor with ✓ / ✗ / ? indicators, and recommends the strongest tier you qualify for.

  • Auto-evaluated: min score, max DTI, ratio tiers, cash reserves (assets ÷ PITI), minimal-increase-in-housing-payment ($100 or 5% rule).
  • Manual checkboxes for the rest: significant additional income, VA residual, no discretionary debt, Energy Efficient Home — your selections persist while you're on the loan.
  • Hover the pill (without clicking) to see the full ZHL guideline matrix as a quick reference.

FHA Collections + Disputed badges ($2k / $1k caps)

Full application → Liabilities

Live cumulative-balance badges that flag when the file approaches FHA's $2,000 collections cap or $1,000 disputed-derogatory cap.

  • Reads liabilities through the React-fiber bridge — no need to expand each row.
  • Excludes medical collections (counted separately by FHA), charge-offs (don't count toward either bucket), and zero-balance rows.
  • Detects "ACCT IN DISPUTE" in the Remarks field — LOP's structured dispute flags are never populated in practice.

FHA + Non-Permanent Resident Alien warning

Full application — any page

Sticky red banner across the top whenever the loan is FHA AND any borrower's citizenship is Non-Permanent Resident Alien. HUD removed NPRAs from FHA eligibility on May 25, 2025 — this catches the combo before it ships to underwriting.

VA Residual Income + Student Loan Calc

Full application → Liabilities (per borrower pair)

Run Residual Income Calc reads income, debts, PITI, family size, and state, then shows residual vs. the VA table requirement with editable Non-Taxable / Maintenance & Utilities / Childcare rows.

Calc Student Loans fills monthly payments on student-loan liabilities that have no payment listed using FHA / DU / LPA / VA formulas. Now recognizes CENTRAL RESEARCH (the default-collection agency for defaulted federal loans) too.

2-1 Buydown calc + Branded PDF

Scenarios page

Each Conventional scenario gets a Calc 2-1 Buydown button. The action bar gets a 2-1 Buydown PDF button that generates a borrower-facing comparison sheet with Year 1 / Year 2 / Year 3+ rates and PITIA payments, savings, total buydown cost, and the closing-cost impact (with or without seller credit).

  • Side-by-side columns when multiple scenarios are selected.
  • Auto-disabled when LOP's own Generate PDF is disabled (e.g. RE-PRICE pending).

Bulk-delete tasks

Tasks → Unsent OR Awaiting borrower section

Adds a checkbox column and a Delete Selected button. Check the boxes for the tasks you want gone, click Delete Selected, and the extension clicks through LOP's per-task confirm dialog for each one — you only confirm once at the start.

  • Independent selection state per section: checking rows in Unsent doesn't affect Awaiting borrower.
  • UI tears down when the section is empty so it looks like stock LOP.

Loan amount input fix

Scenarios page → Loan amount field

Lets you type a loan amount directly instead of LOP's percentage-only behavior. When the purchase price changes, the loan amount stays put (instead of jumping with the percentage).

Scenario sort + Select all

Pricing & Scenarios

Sort buttons (Rate, Payment, Cash to close, etc.) plus a Select all checkbox so you can pick every visible scenario in one click.

Auto-tab to Call Details / Messaging

Salesforce console

When you take an inbound call, the console auto-clicks the Call Details tab. When an inbound SMS arrives, it auto-clicks the Messaging tab. No more hunting through tabs while the borrower is on the line.

📧 Gmail

Runs on: mail.google.com

Drag attachments anywhere

Any email with attachments

Every attachment chip gets a small green ↓ badge once the file is cached (orange ⋯ while caching). Drag the chip and drop on:

  • LOP file-upload areas (Loan documents, task uploads, etc.).
  • Slack, file inputs, or any other website that accepts file drops.
  • Your own Gmail reply (popup compose OR inline reply) — works as of v1.19.8.

Up to 25 MB per file for cross-tab drag (Chrome's IPC limit). Larger files still drag to in-Gmail composes.

Caller ID on incoming-text emails

Gmail inbox / open email

When a Switchboard "Do Not Reply: Incoming Text Message from <phone>" email arrives with just a phone number (no name), a blue pill appears next to the subject with the Salesforce contact's name. Same plumbing as the Salesforce-side Caller ID, so matches stay consistent.

Gmail layout tweaks + Salesforce promotions auto-hide

Gmail (any view) and Salesforce
  • Compose attachment area no longer hides under the toolbar when you attach more than one file.
  • Salesforce "Show Promotions" panel is auto-dismissed.

☁️ Salesforce

Runs on: *.lightning.force.com, *.my.salesforce.com, Genesys Cloud

Mark All As Read

Salesforce Messaging panel → header (next to "New thread")

One-click button that walks every unread thread in the inbox, opens each (which is how Salesforce stamps a read receipt), then clicks Back to return. After the run, every thread is unbold and the unread counts are gone.

  • Detects unread via bold subject text, the right-side unread-count pill, or the unread class on the row.
  • Heavy console logging at every step — failure modes are debuggable without round-tripping for a new build.

Caller ID badge on inbound calls + voicemails

Salesforce console, Genesys Cloud embedded panels

When a phone number appears in the UI (inbound call, voicemail, call history row), the extension queries Salesforce for a matching Contact / Lead / Loan and stamps a blue pill with the borrower's name next to the number. 5-minute lookup cache so popular numbers don't hit the API repeatedly.

SMS quick-add: Co-Borrower / Buyer's Agent

Salesforce SMS panel → New thread

One-click buttons that look up the Co-Borrower's and Buyer's Agent's phone numbers from Salesforce and add them as participants to the SMS thread — no copy/paste from the Contact record.

Open SMS button on Contact records

Salesforce Contact / Lead record pages

Adds an Open SMS button next to the phone number that jumps straight into the messaging panel with that number pre-filled.
